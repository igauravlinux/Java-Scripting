<h1>JavaScript Object vs JSON</h1>
// Note:- JSON me Keys hamesha double quotes me hoti hain.
| JavaScript Object                   | JSON                                  

<hr>

| Keys without quotes chal sakti hain | Keys double quotes me honi chahiye |
| Function ho sakta hai               | Function allowed nahi              |
| Undefined ho sakta hai              | Undefined allowed nahi             |
| Program ke andar use hota hai       | Data transfer ke liye use hota hai |
